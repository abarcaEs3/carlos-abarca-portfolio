## Getting Started

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/abarcaEs3/carlos-abarca-portfolio.git
   ```

2. **Navigate to the project:**
   ```bash
   cd carlos-abarca-portfolio
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

### Development

- **Start the Sass watcher:**
  ```bash
  npm run sass
  ```
  > This watches the SCSS file and automatically generates the compiled CSS file.
